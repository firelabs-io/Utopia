# How to download utopia

- install [processing](https://processing.org/download) (confirm your using binary compatible with your os)
- install the repo (github/carykh/utopia -> code -> download as zip) or `git clone https://github.com/carykh/utopia.git`
- use processing on the folder you downloaded(so you can atually use it!)
- click on arrow button to run it
